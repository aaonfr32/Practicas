# Introduction to Web Applications



En aquest mòdul d'Introduction to Web Applications, el que he après i el que m'ha ensenyat la plataforma a nivell tècnic ha estat entendre com s'estructura una aplicació web per dins abans de buscar-hi vulnerabilitats. Concretament, he treballat la diferència entre el Front End (HTML, CSS i JavaScript que s'executa al navegador) i el Back End (el servidor, les APIs i les bases de dades), així com la comunicació entre tots dos mitjançant peticions HTTP/HTTPS i l'ús de formats com JSON o XML per intercanviar dades. També m'ha servit per introduir-me a les vulnerabilitats més típiques de l'OWASP Top 10 (com SQL Injection o XSS) i entendre per què mai s'ha de confiar en la validació de dades només a la part del client.



* Inspeccionar el codi font: He fet servir les eines de desenvolupador del navegador (DevTools) per revisar l'HTML i el JavaScript carregat a la web, buscant informació exposada o comentaris interns deixats pels desenvolupadors.
* Desofuscar codi JavaScript: He agafat fragments de codi JS que estaven ofuscats perquè no s'entenguessin a simple vista i he utilitzat eines de desofuscació per formatar-los, llegir la seva lògica i trobar-hi dades ocultes per treure les flags.
* Analitzar peticions i APIs: He revisat com viatgen les dades entre el client i el servidor paràmetres GET, POST i capçaleres per entendre com respon l'aplicació davant de diferents entrades.
